# 재고 동시성 제어 방식 성능 비교

## 1. 실험 목적

동일 상품에 주문 요청이 집중되는 상황에서 다음 세 가지 재고 동시성 제어 방식의 처리 성능과 성공률을 비교한다.

1. 낙관적 락 (Optimistic Lock)
2. 낙관적 락 + 재시도 (최대 5회 시도)
3. 비관적 락 (Pessimistic Lock)

단순 요청 처리 속도뿐 아니라 실제 주문 성공률과 재시도 비용을 함께 분석하는 것이 목적이다.

## 2. 테스트 환경

- Java 21
- Spring Boot 3.5.7
- Spring Data JPA / Hibernate
- PostgreSQL 17 (Testcontainers)
- JUnit 5
- ExecutorService / CountDownLatch

### 실험 조건

| 항목 | 설정 |
|---|---|
| 초기 재고 | 10개 |
| 동시 주문 요청 | 10건 |
| 요청당 주문 수량 | 1개 |
| 워밍업 | 2회 |
| 실제 측정 | 7회 |
| 측정 기준 | 전체 소요 시간의 중앙값 |
| 재시도 정책 | 최대 5회 시도, 점진적 대기 + Jitter |

각 측정마다 새로운 상품과 재고를 생성했다.

## 3. 실험 결과

| 지표 | 비관적 락 | 낙관적 + 재시도 | 낙관적 락 |
|---|---:|---:|---:|
| 총 요청 수 | 70 | 70 | 70 |
| 성공 주문 | 70 | 64 | 7 |
| 실패 주문 | 0 | 6 | 63 |
| 성공률 | 100% | 91.4% | 10% |
| 전체 시간 중앙값 | 54.64ms | 177.47ms | 17.46ms |
| 중앙값 실행의 P95 | 54.44ms | 177.33ms | 17.35ms |
| 중앙값 실행의 전체 요청 처리율 | 183.02 req/s | 56.35 req/s | 572.86 req/s |

### 비관적 락

- 7회 모두 주문 10건 성공
- 재고 행에 대한 잠금을 획득한 후 순차적으로 처리
- 전체 소요 시간은 43.45~60.21ms 범위

### 낙관적 락 + 재시도

- 총 70건 중 64건 성공
- 버전 충돌 시 새로운 트랜잭션에서 재시도
- 재시도로 성공률이 개선됐지만 대기 및 재실행 비용 발생
- 전체 소요 시간은 171.72~190.54ms 범위

### 낙관적 락

- 7회 모두 10건 중 1건 성공
- 나머지 요청은 버전 충돌로 실패
- 전체 소요 시간은 짧았지만 주문 성공률은 낮았음

## 4. 결과 분석

### 4.1 비관적 락

현재 고경합 환경에서는 비관적 락이 가장 안정적인 결과를 보였다.

행 잠금으로 요청들이 대기한 후 재고를 수정했으며, 재시도 로직 없이 모든 주문을 성공시켰다.

### 4.2 낙관적 락

재시도가 없는 낙관적 락은 충돌을 빠르게 감지했지만 주문 성공률이 10%에 그쳤다.

전체 요청 처리율이 높다는 사실만으로 실제 주문 처리 성능이 좋다고 판단할 수 없음을 확인했다.

### 4.3 낙관적 락 + 재시도

재시도 정책 적용 후 성공률이 10%에서 91.4%로 개선됐다.

다만 충돌 발생 시 트랜잭션 재시작, DB 재조회, 대기 시간이 추가되므로 전체 처리 시간은 증가했다.

현재 구현의 재시도 대기 정책도 측정 결과에 영향을 주었다.

## 5. 실험의 한계

이번 결과는 제한된 로컬 환경에서 측정한 탐색적 벤치마크다.

- 동시 요청 수가 10개로 적음
- P95 표본이 충분하지 않음
- DB 커넥션 풀 크기를 명시적으로 통제하지 않음
- JVM과 DB 내부 상태의 영향을 완전히 제거하지 않음
- 각 락 방식의 측정 순서가 고정되어 있음
- 재시도 횟수 및 실제 대기 시간을 별도로 측정하지 않음
- 단일 상품에 요청이 집중되는 고경합 상황만 검증함

따라서 특정 락 방식이 일반적으로 더 빠르다고 결론 내릴 수는 없다.

## 6. 잠정 결론

동일한 재고 행에 동시 주문이 집중되는 현재 테스트 환경에서는 비관적 락이 가장 높은 주문 성공률과 안정적인 처리 결과를 보였다.

낙관적 락은 재시도 정책을 통해 성공률을 높일 수 있었지만, 재시도 비용이 추가됐다.

향후 다양한 경합 수준과 커넥션 풀 조건에서 반복 측정하여 재고 처리 전략을 결정할 예정이다.
