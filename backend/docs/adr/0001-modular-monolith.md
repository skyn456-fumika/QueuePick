# ADR-0001: 모듈러 모놀리스로 시작한다

- 상태: 채택
- 일자: 2026-10-26

## 배경
첫 버전에서는 재고 차감과 주문 생성 사이의 데이터 정합성이 가장 중요하다.

## 결정
하나의 Spring Boot 애플리케이션과 PostgreSQL DB에서 시작한다. `product`, `inventory`, `order` 등 도메인 경계를 패키지로 구분한다.

## 근거
- 단일 DB 트랜잭션으로 주문과 재고의 원자성을 검증하기 쉽다.
- 네트워크 장애 및 분산 트랜잭션 복잡성을 초기 범위에서 배제한다.
- 향후 측정된 필요가 있을 때 모듈 단위로 분리할 수 있다.

## 대안
- 초기 MSA: 서비스별 배포는 가능하지만 첫 단계의 운영·정합성 복잡성이 커진다.

## 재검토 조건
독립 배포 필요 또는 모듈별 확장 요구가 실제 데이터로 확인될 때.
