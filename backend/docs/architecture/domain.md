# QueuePick 도메인 초안

## MVP 범위
- Product: 한정 수량으로 판매하는 상품. 판매 시작 시각과 가격을 가진다.
- Inventory: 상품별 가용 수량과 낙관적 락 버전을 가진다.
- Order: 주문 시점 가격과 수량, 상태를 보존한다.

## 불변식
1. 재고 수량은 0 미만이 될 수 없다.
2. 주문 수량은 1 이상이다.
3. 주문 시점 가격은 이후 상품 가격 변경과 독립적이다.
4. 재고 차감과 주문 생성은 미래의 애플리케이션 서비스에서 동일 DB 트랜잭션으로 실행한다.

## 이번 단계에서 하지 않는 것
인증, 결제, Kafka, Redis 및 주문 API는 아직 구현하지 않는다. `@Version`을 적용했지만 동시성 통합 테스트 이전에 충돌 방지 기능이 검증되었다고 주장하지 않는다.
